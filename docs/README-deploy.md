# VibeSpeak Career Simulator scaffold

This scaffold includes a minimal Node + TypeScript backend and a React + TypeScript frontend skeleton for the Career Simulator feature.

Branches to create locally:
- feature/career-sim-backend
- feature/career-sim-frontend

Instructions:
1. Copy the `backend/` and `frontend/` folders into your repository root.
2. In `backend/` run:
   - npm install
   - npm run dev
3. In `frontend/` run:
   - npm install
   - npm start

Apply patch locally (example):
- git checkout -b feature/career-sim-backend
- git add backend/
- git commit -m "feat(simulator): add initial backend scaffold"
- git push origin feature/career-sim-backend

- git checkout -b feature/career-sim-frontend
- git add frontend/
- git commit -m "feat(simulator): add initial frontend scaffold"
- git push origin feature/career-sim-frontend

Then create PRs from these branches.
